# ФЕЛИКС | E-commerce Strategy 2026

Отдельный интерактивный сайт-презентация стратегии развития e-commerce мебельной компании «ФЕЛИКС».

## Содержание

- Аудит текущей цифровой инфраструктуры и клиентских сценариев
- Стратегия развития интернет-магазина и B2B (продаж организациям)
- Сравнение с конкурентами
- Коммерческие инициативы и управленческая аналитика
- Интерактивная дорожная карта на 365 дней: 1–120, 121–240, 241–365

## Обновления

- Сокращения в презентации сопровождаются пояснениями в скобках.
- Сроки ориентировочные: три этапа в течение 365 дней без безусловных обязательств по каждой задаче.
- Прогресс чек-листа сохраняется локально в браузере.

## Публикация GitHub Pages

1. Откройте **Settings → Pages** репозитория.
2. В **Build and deployment** выберите **Deploy from a branch**.
3. Укажите ветку **main** и папку **/(root)**.
4. Нажмите **Save**.
